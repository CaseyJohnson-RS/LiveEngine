# Документация

**Клиент** `client` - подключённое к движку приложение. На одной машине может быть запущенно несколько клиентов.

**Соединение** `connection` - открытый WebSocket-канал.

**Движок** - Процесс, держащий домен и WebSocket-сервер. Запускается у одного из участников.

**Идентификатор** `ID` - уникальное целое число, которое присваивается каждому новому клиенту. Он публичный и его знают все. Каждый может на него сослаться.
