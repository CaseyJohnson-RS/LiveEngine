# 0005. Справедливый первый ход — на лету

**Контекст.** Сначала расписание первых ходов составлялось заранее, при
старте игры. Оно ломалось, если кто-то выбывал насовсем: его партии
доставались следующим по кругу, и равенство нарушалось.

**Решение.** В начале каждой партии её начинает тот из оставшихся, кто
начинал партии реже всех; при равенстве — случайный из них. Правило — в
[партии](../rules/match.md).

**Последствия.** Игра хранит счётчик начатых партий у каждого игрока, а не
расписание. У оставшихся разница никогда не превышает одной, даже при
выбываниях. Заранее узнать, кто когда начинает, нельзя — это и не нужно.
