# 0009. Раскрытые позиции — часть раунда

**Контекст.** Позиции ряда, раскрытые игроку, хранились в его месте. Но
место живёт всю партию, а раскрытая позиция имеет смысл только для своего
ряда. Их приходилось вручную очищать при каждой смене раунда, ради этого
в правило «мёртвое место заморожено» пришлось добавить исключение, а
проверить, что позиция вообще есть в ряду, место не могло — размер ряда
ему неизвестен.

**Решение.** Раскрытые позиции каждого игрока хранятся в раунде, рядом с
рядом, к которому относятся. Модель — в
[раунде](../architecture/domain/round.md).

**Последствия.** Раскрытые позиции исчезают вместе с рядом — ручной
очистки нет. Из правила заморозки места уходит исключение. Раунд
проверяет, что раскрываемая позиция есть в ряду. «Какие позиции» и «что
в них» лежат в одном месте, и видимость строится из одного объекта. Поле
раскрытых позиций уходит из места (`Seat`) и его снимка.
