# Принципы

Основные принципы, на которых строится движок.

## 1. Правила — функции домена

Сущности хранят состояние и охраняют свои инварианты. Правила игры —
функции домена, которые проверяют команду и меняют сущности. Прикладной
слой вызывает только правила.

- Функции правил живут в домене, а не в прикладном слое.
- Прикладной слой не меняет сущности напрямую — только через правила.
- Правило сначала проверяет всё, потом меняет: если проверка не прошла,
  агрегат остаётся нетронутым.

## 2. Клиент воссоздаёт картину мира сам

Каждый клиент строит у себя картину мира по приходящим изменениям. Если
соединение оборвалось или клиент заподозрил рассинхрон, он в любой
момент запрашивает текущий снимок и строит картину заново.

Для домена это значит:

- в любом состоянии игры домен умеет отдать снимок для конкретного
  игрока — с учётом того, что этому игроку видно;
- запрос снимка ничего не меняет: это вопрос, а не команда.
