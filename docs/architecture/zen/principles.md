# Принципы

Основные принципы, на которых строится движок.

## 1. Правила — функции домена

Сущности хранят состояние и охраняют свои инварианты. Правила игры —
функции домена: они проверяют команду, меняют сущности и возвращают
**события** и **сообщения**. Прикладной слой вызывает только правила.

- Функции правил живут в домене, а не в прикладном слое.
- Прикладной слой не меняет сущности напрямую — только через правила.
- Правило сначала проверяет всё, потом меняет: если проверка не прошла,
  агрегат остаётся нетронутым.
- **События** — полная правда о том, что произошло, включая скрытое; они
  идут в историю событий. **Сообщения** — то, что конкретный игрок узнаёт
  об этом; кому и что сообщить, решает само правило.

## 2. Клиент воссоздаёт картину мира сам

Каждый клиент строит у себя картину мира по приходящим сообщениям. Если
соединение оборвалось или клиент заподозрил рассинхрон, он в любой
момент запрашивает текущий снимок и строит картину заново.

Главное требование:

> **Снимок + все сообщения игроку после него = следующий снимок.**

Клиент с верным снимком, применяя к нему приходящие сообщения, всегда
приходит ровно к тому, что вернул бы новый запрос снимка.

- **Любое видимое игроку изменение состояния сообщается ему.** Не только
  «интересное» (выстрел, фишка), но и служебное: сменилась фаза, игрок
  подтвердил, перешёл ход, изменилось присутствие.
- **Сообщения смысловые, клиент знает правила.** Сообщение говорит, *что
  произошло* («выстрел из каморы 3 в B, патрон был»), а изменения
  состояния клиент выводит сам по правилам.
- **Сообщение несёт только то, что клиент не может вычислить:**
  результаты случайности, скрытое, которое этому игроку теперь можно
  знать, и ставший видимым выбор других игроков.
- **Отклонение команды — не сообщение о происходящем.** Это ответ
  отправителю; состояние оно не меняет.

Для домена это значит:

- в любом состоянии игры домен умеет отдать снимок для конкретного
  игрока — с учётом того, что этому игроку видно;
- запрос снимка ничего не меняет: это вопрос, а не команда;
- каждое правило сообщает каждому игроку обо всех видимых ему
  изменениях, которые оно сделало.

Требование «снимок + сообщения = снимок» проверяется тестом.
