# Раунд

Раунд (`Round`) хранит всё, что относится к его ряду и исчезает вместе с ним:

- заряженный каморный ряд;
- раскладки игроков, из которых ряд заряжен;
- начальное число патронов — из ряда его не восстановить: после
  выстрелов и инверсий ряд знает только текущее содержимое;
- позиции ряда, раскрытые каждому игроку.

Чей ход — уровень партии, жизни и фишки — в местах, номер раунда
правилам не нужен. Раскрытые позиции проверяются по ряду: позиции,
которой нет в ряду, раскрыть нельзя.

## Команды

Обе команды отправляет активный игрок. Что можно делать в ход и кто
когда передаёт ход — см. [ход](../../rules/turn.md).

| Команда | Что делает |
| --- | --- |
| Применить предмет | Предмет из своей руки с параметрами, которые ему нужны (цель, камора); срабатывает по своим правилам — см. [предметы](../../rules/items.md) |
| Выстрелить | Применить особый предмет «выстрел» — см. [выстрел](../../rules/turn.md#выстрел) |

После каждой команды правило проверяет исход — см.
[ход](../../rules/turn.md). Если закончилась партия, дальше проверяется,
не закончилась ли игра — см. [игру](../../rules/game.md).

## Снимок

Снимок раунда — то, что игроку можно знать о ряде сейчас. Кто что видит —
см. [видимость](../../rules/visibility.md).

Что входит в снимок раунда:

- начальное число патронов;
- какие каморы отстреляны;
- какие позиции раскрыты каждому игроку;
- вес на своих раскрытых позициях;
- своя раскладка фишек.

Чего в снимке раунда нет: содержимого камор — ни отстрелянных, ни
остальных — и весов камор. Результат каждого выстрела игроки узнают из
сообщения в момент выстрела, а не из снимка.
