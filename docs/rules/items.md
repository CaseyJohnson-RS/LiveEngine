# Предметы `v0.1`

## Оси классификации

Каждый предмет описывается двумя ортогональными осями плюс классом силы:

- **Область действия** — Себя / Ряд / Игрок: что предмет меняет.
- **Функция** — Информация / Баланс / Ресурс / Контроль / Темп / Усиление:
  как именно он это меняет.
- **Класс** — обычный / редкий / потолочный. Потолочный — максимально
  сильная версия эффекта в своей клетке (область × функция), не более
  одного такого представителя на клетку. Класс совпадает со **слоем**
  выдачи (см. [`rules.md`](rules.md)) — обычный = слой 1, редкий = слой 2,
  потолочный = слой 3.

Не все клетки сетки области × функция имеют смысл: у ряда нет жизней или своего темпа хода, поэтому «Баланс» существует только в
области «Ряд», а «Ресурс» и «Темп» — только в «Себя»/«Игрок».

## Описания

- **Одним глазом** Показывает применившему сумму фишек, положенных в
  одну конкретную камору.
- **Во все глаза** Показывает применившему сумму фишек, положенных в
  каждую конкретную камору.
- **Настроечный щит** Активируется проактивно в свой ход; срабатывает позже,
  пассивно, когда применившего выбирают целью — гасит один входящий
  выстрел во время хода следующего игрока.
- **Со всей дури** Следующее собственное попадание (в любую цель)
  наносит не одну, а две единицы урона по жизням.
- **Глоток воды** Гарантированно восстанавливает 1 единицу жизни.
- **Сомнительное удовольствие** 50% — восстанавливает 2 единицы жизни,
  50% — отнимает 1. Независимый бросок предмета, не связан с экономикой
  фишек: неудачный исход не считается риском в каморном ряду и не даёт
  фишку.
- **Как новый** Восстанавливает жизни до стартового значения раунда.
- **Пасс** Разрешает не стрелять в свой ход — единственное явное
  исключение из правила «выстрел обязателен».
- **Дубль** После обычного выстрела можно выстрелить ещё раз в этот же
  ход, прежде чем передать ход. Структурно то же самое, что было
  сознательно исключено как базовое правило («самовыстрел даёт лишний
  ход») — здесь допустимо именно потому, что это редкий предмет, а не
  бесплатная механика для всех.
- **Джекпот** Мгновенно даёт полный набор фишек на *следующий* раунд, без
  необходимости зарабатывать их риском. Единственный способ обойти
  правило «фишки только через риск» — поэтому обязан быть очень редким, а
  не потому что экономика фишек пересмотрена.
- **Реверс** Меняет физическое содержимое конкретной каморы напрямую —
  реально меняет общий баланс патронов в ряду.
- **Хочу еще** Добавляет один патрон в ряд — увеличивает общий
  баланс.
- **Мне страшно** Убирает один патрон из ряда — уменьшает общий
  баланс. Позиция, откуда снимается патрон, не выбирается игроком —
  определяется системой.
- **Что тут у нас** Расходует конкретную ещё не отстрелянную камору
  без выстрела в кого-либо — камора выбывает из игры, её исход никому не
  наносит урона.
- **ХАХхаахХАх** Берёт текущее число ещё не найденных патронов
  (`remain_cartridges`) и заново раскидывает их по ещё не разыгранным
  каморам — с теми же весами, что были при исходной раскладке фишек.
  Общий баланс ряда не меняется, только то, где именно среди нерешённых
  камор физически находятся патроны. Реализационно — повторный вызов
  `sample_weighted_mask` на подмножестве нерешённых камор с их весами и
  `k = remain_cartridges`, готовая математика уже есть в
  [`core/weighted_subset_sampler.py`](../core/weighted_subset_sampler.py).
- **Подыграй мне** На следующий ход указанного игрока, который
  теряет право выбирать цель. Применяющий может указать ЛЮБОГО игрока,
  считая себя и самого игрока. Не ограничивает выбор каморы — только цель.
  В строго дуэльном формате (два игрока) эффекта не даёт — выбор и так
  бинарный, раскрывается только при трёх и более игроках за столом.
- **Попробуй вот эту** На следующий ход указанного игрока он обязан стрелять
  именно из каморы, названной применившим. Если эту камору потратят
  раньше (кто-то другой выстрелит из неё до хода цели) — ограничение
  снимается.
- **Пора делиться** Забирает у выбранного оппонента либо один его предмет,
  либо небольшую фиксированную сумму банка — что именно из двух категорий
  забрать, решает применивший, но какой конкретно предмет уйдёт (если
  выбран предмет) — случайно, не по выбору. Без хирургического снятия
  конкретного (например, потолочного) предмета сила эффекта не зависит от
  того, чем именно силён оппонент.
