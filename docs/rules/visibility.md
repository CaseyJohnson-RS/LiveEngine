# Видимость

Единственный источник того, кто что знает.

## Игра и игроки

| Информация | Кто знает |
|---|---|
| Состояние игры: лобби / идёт партия / конец | все |
| Настройки хоста | все |
| Кто хост | все |
| Список игроков | все |
| Присутствие каждого игрока | все |
| Сколько партий сыграно | все |
| Сколько партий начал каждый | никто — служебные данные движка |
| В конце игры | все — история событий |

## Партия и места

| Информация | Кто знает |
|---|---|
| Состояние партии: подготовка / идёт раунд / окончена | все |
| Очередь хода, чей ход, номер хода | все |
| Жизни каждого, жив ли | все |
| Предметы на руках у каждого | все |
| Эффекты на каждом игроке | все |
| Число фишек у каждого | все |
| Применения предметов | все, если в описании предмета не сказано иначе |

## Подготовка

| Информация | Кто знает |
|---|---|
| Текущая фаза: выдача / раскладка | все |
| Число камор — с начала подготовки, до раскладки фишек | все |
| Кто подтвердил текущую фазу | все |
| Что выпало игроку при выдаче и какую руку он выбрал | только он сам |
| Слои раунда | никто — внутренняя логика движка |
| Своя раскладка фишек | только владелец (и весь раунд) |
| Чужие раскладки | никто |

## Раунд и ряд

| Информация | Кто знает |
|---|---|
| Начальное число патронов — после раскладки, при зарядке («2 патрона из 8») | все |
| Какие каморы отстреляны | все |
| Выстрелы: кто, в кого, из какой каморы, результат | все |
| Выдача или невыдача фишки за риск | все |
| Какие позиции ряда раскрыты каждому | все |
| Вес на раскрытых позициях | только тот, кому раскрыто |
| Итоговые веса камор | никто |
| Какие каморы заряжены | никто |
| Результат инверсии (какой стала камора) | никто |
| Сколько патронов осталось | не показывается, но вычислимо |

Текущее число патронов нигде не отображается явно. Игроки отслеживают его
сами по публичным событиям: выстрелам и их исходу, инверсиям, выдаче
фишек. Движок не делает эту арифметику за них. Выдача фишки за риск
особенно показательна: она однозначно сообщает, остались ли в ряду
патроны, не раскрывая их числа.

Инверсия каморы с неизвестным содержимым вносит неопределённость ±1: не
знает точно даже тот, кто инвертировал. Неопределённость снимается, когда
эту камору потратят. В остальном число патронов вычислимо внимательным
игроком.

Помнить, что происходило, — забота самого игрока. Движок не пересылает
прошедшее заново: сообщения, пропущенные во время потери связи, не
повторяются. Все события целиком — только в истории событий в конце
игры.
