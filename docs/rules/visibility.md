# Видимость

| Информация | Кто знает |
|---|---|
| Число камор — до раскладки фишек | все |
| Число патронов — после раскладки, при зарядке | все |
| Выстрелы: кто, в кого, из какой каморы, результат | все |
| Применения предметов | все |
| Результат инверсии (какой стала камора) | никто |
| Предметы на руках у каждого | все |
| Выдача: что выпало игроку, что он оставил и выбросил | все |
| Выдача или невыдача фишки за риск | все |
| Своя раскладка фишек | только владелец |
| Раскрытое предметами (веса камор) | только применивший |
| Чужие раскладки, итоговые веса камор | никто |
| Какие каморы заряжены | никто |
| Сколько патронов осталось | не показывается, но вычислимо |
| В конце игры | все — полный лог |

Текущее число патронов нигде не отображается явно. Игроки отслеживают его
сами по публичным событиям: выстрелам и их исходу, инверсиям, выдаче
фишек. Движок не делает эту арифметику за них.

Инверсия каморы с неизвестным содержимым вносит неопределённость ±1: не
знает точно даже тот, кто инвертировал. Неопределённость снимается, когда
эту камору потратят. В остальном число патронов вычислимо внимательным
игроком.
