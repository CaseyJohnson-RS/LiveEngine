# Правила игры

Рабочий свод правил. Что ещё не решено — в
[открытых вопросах](../README.md#открытые-вопросы).

## Идея

N игроков сидят за столом. Перед ними — каморный ряд (не револьвер
физически), выложенный на столе. Игроки по очереди выбирают камору и
цель и стреляют. Это самый обычный ход; в общем случае игрок в свой ход
применяет предметы, а выстрел — один из них (см. [ход](turn.md)). Игра
идёт партиями, партия — раундами, раунд — ходами.

```mermaid
flowchart TD
    L["Лобби<br/>Join, хост задаёт настройки и число партий"] --> P

    subgraph P["Партия"]
        direction TB
        P0["Жизни всем<br/>очередь хода тасуется<br/>первым ходит тот, кто начинал реже всех"] --> PR

        subgraph PR["Подготовка"]
            direction TB
            R1["Выдача предметов по слоям<br/>игрок выбирает свою руку"]
            R2["Раскладка фишек<br/>одновременно"]
            R1 --> R2
        end

        subgraph R["Раунд"]
            direction TB
            R3["Ряд заряжается по весам"]
            T["Ход активного игрока:<br/>применяет предметы, пока действие<br/>не передаст ход"]
            R3 --> T
            T -- "ряд не исчерпан,<br/>живых > 1" --> T
        end

        PR --> R
        R -- "ряд исчерпан,<br/>живых > 1" --> PR
    end

    P -- "жив 1, партии ещё есть → сброс всего" --> P
    P -- "жив 1, партий больше нет" --> F["Конец игры<br/>каждому — полный лог"]
    P -- "игроков меньше двух" --> F
```
