# Партия

```mermaid
flowchart TD
    S["Начало партии<br/>жизни всем поровну, фишек и предметов нет"] --> Q["Очередь хода тасуется"]
    Q --> F["Первый ход — по правилу первого хода"]
    F --> PR[["Подготовка"]]
    PR --> R[["Раунд"]]
    R --> A{"Живых больше одного?"}
    A -- да --> N["Раунд начинает<br/>активный игрок"]
    N --> PR
    A -- нет --> W["Конец партии<br/>победитель — последний живой"]
    PR -. "кто-то выбыл,<br/>жив один" .-> W
```

- **Жизни.** В начале партии движок выбирает число жизней в пределах от
  минимума до максимума, заданных хостом, — одно и то же для всех
  игроков. Как и конфигурация раунда, это одна заменяемая формула;
  **текущая** — случайное число от минимума до максимума. Дальше жизни
  тратятся и переносятся между раундами без сброса.
- Партия заканчивается, когда в живых остаётся ровно один игрок. Это
  условие партии целиком, а не отдельного раунда.
- Когда партия заканчивается, сбрасывается всё: жизни, фишки, предметы и
  эффекты у всех игроков. Следующая партия начинается с нуля.
- **Очередь хода** — это круг. Она тасуется случайно один раз при старте
  партии и не меняется до её конца; первый ход определяет, с кого круг
  начинается; следующая партия тасует заново — сознательно, как
  фича, а не только ради баланса.

## Первый ход

```mermaid
flowchart TD
    A["Оставшиеся игроки"] --> B["Те, кто начинал партии<br/>реже всех"]
    B --> C{"Такой один?"}
    C -- да --> D["Он начинает партию"]
    C -- нет --> E["Случайный из них"] --> D
    D --> F["Его счётчик начатых партий +1"]
```

Каждый игрок должен одинаково часто начинать партию. Поэтому в начале
каждой партии её начинает тот из оставшихся игроков, кто начинал партии
реже всех; если таких несколько — случайный из них. Так у оставшихся
игроков разница в числе начатых партий никогда не превышает одной, даже
если кто-то выбыл насовсем. Расписание заранее не составляется.

Выбранный так игрок становится активным. Каждый раунд начинает тот, кто
активен, когда раунд начинается (кто и когда становится активным — см.
[ход](turn.md)).
