# Live Game Engine

Это движок моей небольшой игры, которая является в каком-то смысле копией
[Buckshot Roulette](https://en.wikipedia.org/wiki/Buckshot_Roulette).

Главным отличием этой игры является каморный ряд, разложенный перед игроками с
возможностью выбора каморы.

В данный момент планируется писать именно ядро системы, которое будет запущено
у одного из игроков.
